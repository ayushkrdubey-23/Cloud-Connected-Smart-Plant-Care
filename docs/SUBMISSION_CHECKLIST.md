# Submission Checklist

## Functional
- [ ] Backend starts.
- [ ] Swagger opens.
- [ ] Frontend starts.
- [ ] Simulator starts.
- [ ] Dashboard receives live data.
- [ ] Moisture chart updates.
- [ ] Plant health displays.
- [ ] Automatic watering works.
- [ ] Manual watering works.
- [ ] Water tank displays.
- [ ] Refill works.
- [ ] Watering history displays.
- [ ] Alerts display.
- [ ] Pytest runs successfully.

## GitHub
- [ ] README.md exists.
- [ ] docs/ folder is uploaded.
- [ ] screenshots/ is uploaded if required.
- [ ] `.env` is not uploaded.
- [ ] `.venv/` is not uploaded.
- [ ] `node_modules/` is not uploaded.
- [ ] `plant_care.db` is not uploaded unless required.
- [ ] Main branch is pushed.

## Final Review
Open the public repository and confirm that no credentials or private configuration are visible.
