# Project Overview

## Project Title
**Cloud-Connected Smart Plant Care & Watering System**

## Author
**Ayush Kumar Dubey**

## Overview
This project is an IoT and Cloud Computing oriented smart plant-care prototype. A virtual IoT sensor simulator generates soil moisture, temperature, humidity, and light readings. The readings are sent to a FastAPI REST backend, stored in SQLite, processed by the watering automation and alert services, and displayed through a React dashboard.

## Objectives
- Monitor plant and environmental conditions.
- Store sensor readings.
- Automate watering decisions.
- Track a virtual water tank.
- Support manual watering and refill.
- Generate alerts.
- Provide a responsive monitoring dashboard.

## Current Scope
The submission version is a working local MVP using simulated sensors and SQLite. Physical ESP32 hardware, production cloud deployment, external notifications, and production authentication are future extensions.

## Main Components
1. Virtual IoT Sensor Simulator
2. FastAPI Backend
3. SQLite Database
4. Watering Automation Engine
5. Alert Service
6. React Dashboard
